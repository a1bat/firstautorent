# FIRST AUTO RENT

Лендинг аренды Tesla Cybertruck с личным водителем в Алматы.

Статический сайт: один HTML-файл, папка с изображениями, никакой сборки
и никаких зависимостей.

## Структура

```
index.html        вёрстка, стили и скрипты в одном файле
img/              изображения в формате WebP
robots.txt        для поисковых роботов
sitemap.xml       карта сайта
```

## Домен

Сайт работает на firstautorent.kz. Файл `CNAME` в корне репозитория
обязателен: без него GitHub Pages сбрасывает привязку домена при
каждом пуше. Не удаляйте его.

## Публикация через GitHub Pages

Settings -> Pages -> Source: Deploy from a branch -> ветка `main`,
папка `/ (root)` -> Save. Репозиторий должен быть публичным.

## Что поменять перед запуском

Заменить `firstautorent.kz` на реальный домен в трёх местах:
блок `application/ld+json` и теги `og:url` и `canonical` в `index.html`,
а также в `sitemap.xml` и `robots.txt`.

Номер WhatsApp меняется заменой `77066613705` по всему файлу.

## Первый экран

Заголовок CYBERTRUCK перекрывается горами. Снимок разрезан на два слоя
по линии хребта, надпись стоит между ними:

- `hero-back.webp` - кадр целиком
- `hero-front.webp` - только горы, небо вырезано в прозрачность

Для вертикальных экранов есть отдельная пара `-m`. Нужный файл браузер
выбирает сам через `<picture>`. При замене фотографии обе пары нужно
пересобирать вместе, иначе слои разъедутся.

## Мобильная версия

Отдельная компоновка, не просто сжатый десктоп:

- карточки «Цели» листаются вбок с примагничиванием, а не идут стопкой
- тарифы собраны в компактные карточки, выгода вынесена в плашку
- снизу закреплена панель с WhatsApp и звонком, всплывает после первого экрана
- цели нажатия не меньше 47 пикселей, зазоры от 8

## Робот

Сцена подгружается из Spline по ссылке в `data-scene`. Сейчас это чужая
демонстрационная сцена - для рабочего сайта нужна своя. Не грузится на
экранах уже 1024 пикселей и при включённой экономии движения; если CDN
не ответит за 12 секунд, блок удаляет себя сам.

## Тарифы

Кнопки «Выбрать» открывают WhatsApp с готовым текстом под каждый тариф.
Тексты лежат в ссылках в кодировке URL - при правке цен обновите и их.
