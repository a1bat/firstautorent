# FIRST AUTO RENT

Лендинг аренды Tesla Cybertruck с личным водителем в Алматы.

Статический сайт: один HTML-файл, папка с изображениями, никакой сборки
и никаких зависимостей. Открывается двойным кликом, разворачивается
на любом хостинге копированием файлов.

## Структура

```
index.html        вся вёрстка, стили и скрипты в одном файле
img/              изображения в формате WebP
robots.txt        для поисковых роботов
sitemap.xml       карта сайта
```

## Локальный запуск

Достаточно открыть `index.html` в браузере. Если нужен полноценный
локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Публикация через GitHub Pages

1. Settings -> Pages
2. Source: Deploy from a branch
3. Branch: `main`, папка `/ (root)`
4. Save

Через минуту сайт будет доступен по адресу
`https://a1bat.github.io/firstautorent/`.

Для своего домена: в Settings -> Pages -> Custom domain указать
`firstautorent.kz`, а у регистратора добавить CNAME-запись на
`a1bat.github.io`.

## Что нужно поменять перед запуском

| Где | Что |
|---|---|
| `index.html`, блок `<script type="application/ld+json">` | адрес сайта в поле `url` |
| `index.html`, теги `og:url` и `canonical` | тот же адрес |
| `sitemap.xml`, `robots.txt` | тот же адрес |

Номер WhatsApp `+7 706 661 37 05` уже проставлен во всех ссылках.
Чтобы поменять его, достаточно заменить по всему файлу `77066613705`.

## Первый экран

Заголовок CYBERTRUCK перекрывается горами. Это не эффект CSS: снимок
разрезан на два слоя по линии хребта, надпись стоит между ними.

- `hero-back.webp` - кадр целиком
- `hero-front.webp` - только горы, небо вырезано в прозрачность

Для вертикальных экранов есть отдельная пара `-m`: широкий кадр на
телефоне резал машину пополам. Нужный файл браузер выбирает сам
через `<picture>`.

Если будете менять фотографию первого экрана, обе пары нужно
пересобрать вместе, иначе слои разъедутся.

## Робот

Сцена подгружается из Spline по ссылке в атрибуте `data-scene`.

Важно: сейчас там стоит **чужая демонстрационная сцена**. Она может
исчезнуть в любой момент, и прав на неё у вас нет. Для рабочего сайта
нужно сделать свою сцену в Spline и подставить её адрес.

Сцена не загружается на экранах уже 1024 пикселей и при включённой
у пользователя экономии движения: это несколько мегабайт WebGL, на
телефоне они стоят дороже, чем дают. Если Spline не ответит за
12 секунд, блок удаляет себя сам и первый экран остаётся целым.

## Тарифы

Кнопки «Выбрать» открывают WhatsApp с уже готовым текстом, своим для
каждого тарифа. Тексты лежат прямо в ссылках в кодировке URL - при
правке цен не забудьте обновить и их.

## Лицензия на материалы

Фотографии автомобилей и людей принадлежат FIRST AUTO RENT.

пикселей алгоритмом Real-ESRGAN.
